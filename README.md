# No som RES!

Official website for **No som RES!** — punk rock in Catalan from Barcelona.

Built with [Astro](https://astro.build/) and hand-written CSS, deployed to GitHub Pages.

## Development

```bash
npm install
npm run dev      # local dev server at http://localhost:4321
npm run build    # production build to dist/
npm run preview  # preview the production build
```
